# ARCHIVE

아이패드·아이폰·PC에서 쓰는 **공부 기록 웹앱(PWA)**입니다. 설치할 것도, 빌드할 것도 없이 정적 파일만으로 동작하고, 오프라인에서도 쓸 수 있어요.

## 기능

**공부 / 라이프 / 데일리 모드**로 메뉴와 홈 위젯이 나뉩니다 (사이드바 위 전환 버튼). 데일리 모드는 두 모드의 메뉴를 모두 보여줘요.

공통 메뉴: **캘린더**(일정 + 할 일·디데이·기분·공부시간·지출 모아보기), **계산기**(결과를 가계부로 바로 기록), 할 일, 설정

| 공부 모드 | 내용 |
|---|---|
| 홈 | 하루 한 줄, 디데이, 오늘 공부, 뽀모도로, 할 일, 목표, 주간 그래프 위젯 |
| 메모 | 포스트잇(20색, **사진 메모**, **숨기기**, **단원 미리 만들기**), 암기 카드 · **자유 메모**(손글씨·사진·스티커 노트) |
| 타이머 | 과목별 스톱워치(**순공 / 인강 / 학원·수업** 구분, 순공 따로 집계), 집중 화면(화면 꺼짐 방지), 뽀모도로, 주간/월간 통계 |
| 할 일 | 날짜별 체크리스트, 장기 목표 진행률 |
| 디데이 | 대표 디데이, 배경화면 이미지 생성 |
| 독서·공부 | 책 진행률·별점·밑줄, 과목별 공부 노트 |

| 라이프 모드 | 내용 |

## 아이패드에 설치하기

1. 이 폴더를 웹에 올립니다 (아래 ‘배포’ 참고).
2. 아이패드 **Safari**로 주소를 엽니다.
3. 공유 버튼(⬆️) → **홈 화면에 추가**.
4. 홈 화면 아이콘으로 실행하면 전체화면 앱처럼 동작합니다.

## 배포 (GitHub Pages)

1. GitHub 저장소 → **Settings → Pages**
2. Source: `Deploy from a branch`, Branch: 이 브랜치(또는 main) / `/ (root)` 선택 후 Save
3. 잠시 후 `https://<아이디>.github.io/<저장소>/` 로 접속

로컬 테스트: `python3 -m http.server 8000` 후 `http://localhost:8000`
(서비스워커·모듈 때문에 파일을 더블클릭해서 여는 방식(file://)은 동작하지 않습니다.)

## 데이터와 개인정보

- 모든 기록은 **기기의 브라우저 저장소(IndexedDB)에만** 저장되고 서버로 전송되지 않습니다.
- Safari의 ‘방문 기록 및 웹사이트 데이터 지우기’를 하면 기록이 사라질 수 있으니 **설정 → 백업 파일 저장**을 주기적으로 해주세요. 기기 간 이동도 백업 파일로 합니다.

## 알려진 제약 (웹앱 특성)

- iOS **홈 화면/잠금화면 위젯**은 웹앱으로 만들 수 없습니다 (Swift/WidgetKit 네이티브 앱 필요). 대신 홈 대시보드와 디데이 배경화면 생성 기능을 제공합니다.
- 화면이 꺼지거나 앱이 백그라운드에 있으면 뽀모도로 **소리 알림이 울리지 않을 수 있습니다**. 타이머 자체는 시작 시각 기준이라 다시 열면 정확히 이어집니다. 집중 화면을 켜두면 화면이 유지됩니다.
- ‘함께’ 기능은 서버 없이 공유 코드로 주고받는 방식입니다. 실시간 스터디 그룹(자동 동기화)에는 Firebase/Supabase 같은 백엔드가 필요합니다.

## 구조

```
index.html, manifest.webmanifest, sw.js   앱 셸 · 설치 정보 · 오프라인 캐시
css/style.css                             디자인 (라이트/다크)
js/app.js                                 라우팅 · 내비게이션 · 1초 틱
js/store.js                               데이터 저장(IndexedDB)
js/timers.js, focus.js                    공부 타이머 · 뽀모도로 · 집중 화면
js/drawpad.js                             꾸미기 패드 (벡터 손글씨·보정·아이템)
js/art.js                                 감정·날씨·스티커·테이프 SVG
js/theme.js, icons.js, quotes.js          테마/글꼴 · 아이콘 · 하루 한 줄
js/views/*.js                             각 메뉴 화면
```

앱 파일을 수정한 뒤에는 `sw.js`의 `VERSION`을 올려야 설치된 앱에 반영됩니다.
